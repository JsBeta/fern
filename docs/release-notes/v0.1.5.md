## 本次更新

### 新增：托盘「配置」窗口

- Windows 托盘右键菜单多了一项「配置」，点开即弹出设置窗体，用原生 Win32 控件实现，**没有引入任何 GUI 库**，依赖依旧为空。
- 可直接修改共享目录（带「浏览…」目录选择框）、监听地址、日志级别、最大连接数、访客权限、页面标题、顶部公告、日志目录，以及回收站开关与保留天数；每项写回对应的 `Fern.Root` / `Fern.Listen` / `Fern.LogLevel` / `Fern.MaxConns` / `Fern.Guest` / `Fern.Title` / `Fern.Notice` / `Fern.LogDir` / `Trash.Enabled` / `Trash.Max.Days`。
- 保存时**只就地改写这些指令所在的行**：文件里的注释、空行，以及窗体不展示的指令（`Fern.User`、`Fern.Mime`、`Trash.Max.Size`、`Trash.Keep.Same` 等）原样保留，所以手写过的 `fern.conf` 不会被压平。写盘前先用 `Config::from_text` 把合并结果整体解析一遍，取值或拼写有错就弹窗提示并且**不落盘**，运行中的配置不受影响。
- 配置文件路径沿用当前生效的 `-c` 或默认查找结果，文件不存在时回退到 `fern.exe` 同目录的 `fern.conf`。

### 新增：保存后热加载，不用重启

- 保存成功后立刻生效：日志级别与日志目录、共享目录、并发上限、访客权限、标题与公告全部换到新值，日志里会看到 `configuration saved` 与 `configuration reloaded`。
- 唯一无法在线切换的是**监听地址**：监听线程卡在 `accept()` 里唤不醒，所以改了端口会走托盘「重启」的同一条交接路径（移除图标 → 以原命令行加 `--wait-pid <旧 pid>` 启动新实例 → 退出旧进程），弹窗会先明确提示「fern 将重启」。

### 新增：`Fern.LogLevel` 指令

- 新增 `Fern.LogLevel`，取值 `error` / `warn` / `info`（默认）/ `debug`。`debug` 会逐个记录请求，排查问题时用；`error` 只记录失败。
- 该级别同时作用于控制台、按天日志文件与 syslog，`--check` 的输出里也会打印当前的 `log level`。
- 日志模块改为可重复初始化，因此从「配置」窗口改级别不需要重启进程。

### 优化：配置窗体排版

- 客户区加宽到 520，所有输入框、按钮、提示文本统一对齐到同一条右边界，提示文案按剩余宽度自适应，不再出现文字被窗口右边缘截断。
- 「监听地址」「日志目录」两条较长的说明改为各占一整行，不再被下一行的控件压住。
- 窗口高度不再是写死的数值：控件排完后用 `AdjustWindowRectEx` 反算外框、`SetWindowPos` 居中，底部保留与四周一致的留白，保存/取消按钮不再贴到客户区底边；小屏会按屏幕尺寸收敛，不会跑到屏幕外。

### 升级说明

直接替换可执行文件即可。配置文件格式向后兼容——`Fern.LogLevel` 是新增的可选项，旧配置文件不写这一行时按 `info` 处理；托盘「配置」窗体重写的仍是原有的那些指令，不改变文件结构。

由 `Fern.Hide 1` 隐藏托盘时没有菜单入口，此时请直接编辑配置文件。

### 校验

下载后可用附件中的 `SHA256SUMS` 校验文件完整性：

```sh
sha256sum -c SHA256SUMS
```
