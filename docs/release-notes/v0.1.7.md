## 本次更新

### 新增：递归搜索

- 工具栏新增搜索框（快捷键 `Ctrl+F`，在文件列表中按 `/` 也可聚焦），一个输入框承担两种行为：
  - **打字即过滤**：不按回车时只在当前目录已加载的列表里匹配，不产生任何请求，页脚显示「匹配数 / 总数 项」，`Esc` 或清空输入框恢复完整列表。
  - **回车递归搜索**：以当前目录为根遍历整个子树，结果页显示「名称 / 位置 / 大小 / 修改时间」，点目录名进入该目录、点文件名直接预览、点「位置」跳到所在目录。
- 匹配默认大小写不敏感子串；关键词里出现 `*` 或 `?` 时自动按通配符匹配（如 `*.log`、`img_??.png`，`\` 可转义），前端即时过滤与服务端搜索结果使用同一套规则。
- 搜索结果来自多个目录，因此明确设计为**只读视图**：复选框置灰，删除/复制/重命名等按钮与快捷键在该视图下不生效，避免同名文件被误操作；`Esc` 返回原目录。
- 从搜索结果打开文件时，预览与在线编辑按文件真实所在目录读写，不依赖当前浏览路径。

### 新增：`GET /_api/search`

- `GET /_api/search?path=/&q=关键词&glob=0&limit=200`，需要列目录权限（`l`）。返回 `{"path","query","glob","items":[{"name","path","parent","isDir","size","mtime","hidden"}],"matched","scanned","dirs","truncated","tookMs","limit"}`，其中 `parent` 即可用于跳转。
- 遍历为实时读取，没有索引，因此设了四重上限：**10 秒 / 20 万条目 / 64 层深度 / 500 条结果**。触顶时返回 `truncated:true`，页面页脚标注「已截断」，不会把不完整结果当成全部。
- 同时最多允许 **2 个搜索**，超出返回 `429 {"error":"search_busy"}`，避免几个并发遍历把磁盘占满；`q` 为空或超过 256 字符返回 `400`，路径不是目录返回 `400`，不存在返回 `404`。
- 安全与一致性：复用列表接口的隐藏文件权限（`s`）；不进入 `.Trash`；跳过符号链接与 Windows 重解析点（junction、挂载文件夹），不会跟随链接逃出共享目录或成环；单个目录无权限读取时跳过并继续，不让整次搜索失败。

### 优化：遍历实现不递归

- 服务端是「每连接一线程、栈 128 KiB」的模型，深目录递归会爆栈，因此遍历使用显式栈迭代；时间检查每 256 个条目做一次，避免大目录里频繁取时钟。

### 升级说明

直接替换可执行文件即可，配置文件与数据目录结构没有变化，也没有新增必填配置。搜索功能不需要索引文件或额外磁盘写入；旧版本客户端（浏览器缓存的前端）看不到搜索框时，强制刷新（`Ctrl+F5`）一次即可。

### 校验

下载后可用附件中的 `SHA256SUMS` 校验文件完整性：

```sh
sha256sum -c SHA256SUMS
```
